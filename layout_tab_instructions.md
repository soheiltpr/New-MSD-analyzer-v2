## How to Use

### Step 1: Refresh Browser
Do a **hard refresh** to load the new code:
- **Mac:** `Cmd + Shift + R`
- **Windows:** `Ctrl + Shift + R`

### Step 2: Click Layout Tab
Click the "📐 Layout" tab at the top

### Step 3: Add Sections
Click any colored button to add a section:
- Click "📈 Add Standard Curve" → A blue-bordered section appears
- Click "📊 Add Results Table" → An orange-bordered section appears
- Keep adding as many as you want!

### Step 4: Manage Sections
Each section has controls in its header:
- **▲ Button** - Move section UP in the layout
- **▼ Button** - Move section DOWN in the layout
- **✕ Remove Button** - Delete this section

### Step 5: Save or Export
- Click "💾 Save Layout" to download configuration as JSON
- Click "🗑️ Clear All" to remove all sections and start over

   - "✅ Section added: section-1"
4. If you see errors (red text), share them with me
